# Mixed

// Week 2, Day 4. Eight rounds on the bag. Still planted, still no pivoting.
//
// Farmer's carry goes to 70 yards. If grip fails before the distance,
// that is information, log where you dropped it.

## Warm-up
Air bike, easy, 4 minutes | rest 0
Ninety ninety hip switches, 10 each side | rest 0
Arm circles, 30 seconds each direction | rest 0

## A - Bag
Heavy bag rounds, 8 x 2 minutes, RPE 7, one minute rest between rounds | rest 60

## B - Carry and squat pair
B1 Farmer's carry, 4 x 70 yards with 2 x 40 pounds | rest 0
B2 Goblet squat, 4 x 15 at 40 pounds | rest 90

## C - Power
Slam ball, 3 x 12 with the 40 pound ball | rest 60

## D - Core
Side plank, 3 x 40 seconds each side | rest 45

## E - Test
Dead hang, 3 x maximum, stopping five seconds short of failure, log every time | rest 90
