# Full Body A

// Week 2, Day 1. RPE ceiling moves to 7 across the board. Swings and
// front squats progress by reps and load, not by adding sets.
//
// Front squat moves to the 40s today. If ten clean reps at 2 x 40 is not
// there, do eight and finish the set. Do not grind.

## Warm-up
Air bike, easy, 3 minutes | rest 0
Wall ankle rocks, 15 each side | rest 0
Ninety ninety hip switches, 10 each side | rest 0
Goblet squat hold, 2 x 30 seconds at 30 pounds | rest 0
Scap pull-ups, 2 x 8 from a dead hang | rest 0

## A - Swings
KB swing, 5 x 15 at 50 pounds, RPE 7 | rest 75

## B - Squat
Double KB front squat, 3 x 10 with 2 x 40 pounds, three seconds down and one second pause | rest 90

## C - Upper pair
C1 Push-ups, 3 x 12 to 18, two seconds down | rest 0
C2 Band-assisted pull-ups, 3 x 8 with a lighter band than week one if possible | rest 90

## D - Carry and core
D1 Suitcase carry, 3 x 50 yards each side at 40 pounds | rest 0
D2 Dead bug, 3 x 10 each side | rest 45
