# Conditioning

// Week 1, Day 2. This is the engine session and it is where the
// one point five mile milestone actually gets built while the calf is
// still off the road. Every watt here transfers.
//
// Log average watts or calories per interval.

## Warm-up
Air bike, easy, 5 minutes | rest 0
Wall ankle rocks, 15 each side | rest 0

## A - Intervals
Air bike intervals, 8 rounds of 40 seconds hard then 80 seconds easy, RPE 7 to 8 | rest 0

## B - Power
Slam ball, 5 x 10 with the 30 pound ball | rest 60

## C - Aerobic
Incline treadmill walk, 12 minutes at ten percent incline and three point zero miles per hour | rest 0

## Cool-down
Calf stretch straight knee, 2 x 45 seconds each side | rest 0
Soleus stretch bent knee, 2 x 45 seconds each side | rest 0
