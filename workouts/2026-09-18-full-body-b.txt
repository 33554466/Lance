# Full Body B

// Week 2, Day 3. Romanian deadlift adds a set. Get-up adds a rep. If the
// get-up still looks rough at 18 pounds it stays at 18 pounds, that lift
// earns weight with technique and nothing else.

## Warm-up
Air bike, easy, 3 minutes | rest 0
Turkish get-up unweighted, 3 each side | rest 0
Ninety ninety hip switches, 8 each side | rest 0
Push-up plus, 2 x 10 | rest 0

## A - Hinge
KB Romanian deadlift, 4 x 10 with 2 x 40 pounds, three seconds down | rest 90

## B - Single leg
Reverse lunge, 3 x 10 each side holding the 30 pound bell | rest 75

## C - Upper pair
C1 Half-kneeling KB press, 3 x 10 each side at 30 pounds | rest 0
C2 Bent-over KB row, 3 x 12 each side at 40 pounds | rest 75

## D - Skill
Turkish get-up, 3 x 3 each side with the 18 pound bell | rest 90

## E - Core
Hollow hold, 3 x 35 seconds | rest 45
