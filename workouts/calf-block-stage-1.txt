# Calf Block Stage One

// Run this SIX days a week, every week, in addition to whatever else is
// programmed. Ten to twelve minutes. Splitting it into two shorter bouts
// across the day progresses faster than one long one.
//
// Injured side goes SECOND on every single-leg movement.
//
// Soreness rule: mild soreness during the work is fine. ANY next-morning
// symptom in the calf means yesterday was too much. Repeat the previous
// day's dose instead of progressing.
//
// GATE TO STAGE 2: twenty or more clean single-leg heel raises on both
// legs, within five reps of each other, and no next-morning symptoms for
// a full week.

## Capacity

Double-leg calf raise, 3 x 15 to 20, three seconds up and three second hold and three seconds down | rest 45
Soleus wall sit, 3 x 45 seconds, knee bent to ninety degrees and up on the toes | rest 45
Single-leg calf raise, 3 x as many as stay clean, cap at 15, injured side second | rest 45
Toe walks, 3 x 30 seconds holding heel height | rest 30
Toe curls, 2 x 20 towel scrunches each foot | rest 0
